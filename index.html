Satu repository, dua tujuan deploy.

Kode disimpan di GitHub, situs statis tayang gratis di GitHub Pages (cloud), dan versi penuh berjalan di VPS sendiri. Isi data di bawah, semua perintah ikut menyesuaikan.

Alur: komputer/HP → push ke GitHub → Actions → Pages (otomatis) dan VPS (lewat SSH).
